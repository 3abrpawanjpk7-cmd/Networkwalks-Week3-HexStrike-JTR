Networkwalks Week 3 Extra Modules: HexStrike-AI MCP & John the Ripper

Week 3 extra practical lab documentation covering HexStrike-AI MCP server setup with Claude Desktop on Kali Linux and PDF password cracking using John the Ripper (`rockyou.txt').

Environment & Tools
* OS / Virtualization: Kali Linux in Oracle VirtualBox
* AI & MCP: Claude Desktop + HexStrike-AI MCP Server
* Password Auditing: John the Ripper (`rockyou.txt`)

Key Steps Completed
* Configured the HexStrike-AI MCP server and connected it to Claude Desktop.
* Verified John the Ripper, extracted the PDF hash, and ran dictionary-based password recovery on Kali Linux.
* Checked background processes, server logs, and terminal outputs to verify execution cleanly.
